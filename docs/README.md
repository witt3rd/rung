# docs — conventions

- Normative documents are `*-props.md`; they are generated by
  `cargo run -p rung-doctrine --bin render` and never edited by hand
  (CI runs `render --check`). `conformance.md` is generated too.
- Everything else is informative: derivations are `*-notes.md`, crate
  designs and contracts are named for their crate (`rung-<crate>.md`),
  and per-theory pages live in `rung-std/`.
- Where an informative document disagrees with a normative one, the
  normative one wins.
- Files starting with `_` are tooling, not documents.
- API reference is rustdoc, not prose here.
